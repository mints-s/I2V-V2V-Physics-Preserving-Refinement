# Objective Design

## Total Objective

```text
L_total = L_visual + lambda_flow L_flow + lambda_temp L_temporal + lambda_id L_identity
```

Optional terms can be added when object masks or trajectories are available.

```text
L_total = L_visual
        + lambda_flow L_flow
        + lambda_temp L_temporal
        + lambda_id L_identity
        + lambda_traj L_traj
        + lambda_mask L_mask
```

This objective is designed to preserve Stage-1 dynamics, not true physical correctness.

## L_visual

`L_visual` improves sharpness, detail, or perceptual quality. If pseudo-HR or target videos exist, this term can use L1, Charbonnier, perceptual loss, or a combination of them. If no paired target exists, this term can be replaced or supplemented by no-reference quality priors, pseudo-targets, or distillation from a stronger enhancer.

## L_flow

`L_flow` preserves Stage-1 dynamics. The optical flow of the refined video `V_hat` should not deviate too much from the optical flow of the Stage-1 video `V0`.

```text
L_flow = EPE(Flow(V_hat), Flow(V0))
```

This term constrains the output refinement head to respect the Stage-1 motion prior generated by the frozen I2V backbone. It does not imply that `Flow(V0)` is physically correct ground truth.

## L_temporal

`L_temporal` reduces flicker and encourages frame-to-frame consistency. A simple version can penalize inconsistent temporal differences:

```text
L_temporal = ||(V_hat_t - V_hat_{t-1}) - (V0_t - V0_{t-1})||
```

Alternatively, it can use temporal warping consistency if optical flow is available.

## L_identity

`L_identity` preserves input image and subject consistency. A simple version can compare the first frame of `V_hat` to the input image or Stage-1 first frame. A stronger version can use perceptual identity features if an appropriate encoder is available.

## Optional L_traj

`L_traj` preserves centroid trajectories for objects of interest. If object masks or detections are available, object centroids can be tracked over time and compared between `V0` and `V_hat`.

```text
L_traj = ||Trajectory(V_hat) - Trajectory(V0)||
```

## Optional L_mask

`L_mask` preserves object mask temporal consistency. If masks are available, temporal IoU between Stage-1 masks and refined output masks can be used.

```text
L_mask = 1 - temporal_IoU(Mask(V_hat), Mask(V0))
```

## Interpretation

The objective is a dynamics-preserving refinement objective. It encourages the head to improve visual/spatio-temporal quality while limiting Stage-1 dynamics drift. It should be described as Stage-1 dynamics preservation, not physical ground truth preservation or guaranteed physical correctness.
